# RoadScan historical Kaggle attempts

This archive contains **30 saved versions across 16 project notebooks**, including successful, failed, cancelled and preparation-only attempts. It preserves saved source, English explanations and available outputs. No training was rerun for archiving. Only volatile execution metadata was removed.

## Scope and exclusions

The personal-photo test notebook (`fork-of-15-roadscan-rdd-pretrained-yolov8s`), its photos, dataset and predictions are excluded at the owner's request. Unrelated retrieval, Arabic classification and Qwen character notebooks are excluded. The five unnamed drafts were inspected: two are default empty templates and three concern other projects.

Each file is a historical snapshot, not a recommended current pipeline. Failed/cancelled attempts do not represent completed experiments; old notes and provisional evaluations are retained as history. Quick Save runtimes are not training durations.

## Attribution and evaluation limits

The baseline copy is attributed to Fajer. Published YOLOv8s RDD2022 weights used in notebook 15 are attributed to SreekarAditya (https://huggingface.co/SreekarAditya/yolo-rdd2022-benchmark). Their RDD2022 diagnostic scores do not prove unseen-data or Saudi-road generalization. Original data and weight binaries remain on Kaggle / the original publisher host. The root notebooks 14 and 15 remain the existing latest exports; this folder adds version history.
