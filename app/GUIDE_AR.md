# دليل RoadScan 3-Eye على Streamlit خطوة بخطوة

## وش هو Streamlit؟
Streamlit مكتبة بايثون تسوي لك موقع من ملف بايثون عادي. كل سطر مثل `st.title(...)` أو `st.slider(...)` يطلع عنصر في الصفحة.
**أهم شي تفهمينه:** كل ما المستخدم يحرك شي (يرفع صورة أو يحرك سلايدر)، Streamlit يعيد تشغيل الملف كامل من أوله لآخره.

---

## الخطوة 1: جهزي جهازك
1. ثبتي **Python 3.11** من python.org. في ويندوز علّمي على خيار *Add Python to PATH*.
2. ثبتي **VS Code** من code.visualstudio.com.
3. حطي مجلد `roadscan-app` كامل في جهازك، مثلاً على سطح المكتب.

## الخطوة 2: افتحي المجلد في VS Code
- File ← Open Folder ← اختاري `roadscan-app`
- افتحي التيرمنال: Terminal ← New Terminal

## الخطوة 3: سوي بيئة خاصة للمشروع (مرة وحدة بس)
```bash
python -m venv .venv
```
فعّليها، ولازم تسوينها كل مرة تفتحين فيها التيرمنال:
- **ويندوز:** `.venv\Scripts\activate`
- **ماك:** `source .venv/bin/activate`

إذا طلعت لك `(.venv)` في أول السطر، معناه البيئة اشتغلت ✅

## الخطوة 4: ثبتي المكتبات (مرة وحدة بس، تاخذ كم دقيقة)
```bash
pip install -r requirements.txt
```

## الخطوة 5: حطي النموذج
- **نموذجكم (run 14، YOLO11s):** حمّليه من مخرجات نوتبوك Kaggle حق ريماس `14-roadscan-team-v2-training`، من المجلد `artifacts_team_v2/best.pt`. وحطيه في مجلد `models/` باسم `best.pt`.
- **(اختياري) النموذج الخارجي (run 15):** إذا حطيتيه في `models/` بأي اسم، مثلاً `external_yolov8s.pt`، بيطلع لك في القائمة الجانبية وتقدرين تختارين بين النموذجين. التطبيق يفهم أسماء الفئات حقته (pothole وغيرها) لحاله.
- ثبتي مكتبة YOLO مرة وحدة، ويفضل على نت سريع: `pip install --no-cache-dir ultralytics`
> بدون النموذج، الصفحة الرئيسية وصفحة النتائج وصفحة Priority Score وصفحة About كلها تشتغل عادي.

## الخطوة 6: شغّلي التطبيق 🎉
```bash
streamlit run Home.py
```
بيفتح لك المتصفح على `http://localhost:8501`. ولما تبين توقفينه: اضغطي `Ctrl + C` في التيرمنال.

---

## وش في كل ملف؟
| الملف | وش يسوي |
|---|---|
| `Home.py` | الصفحة الرئيسية |
| `pages/1_Image_Analysis.py` | ترفعين صورة وتطلع لك: مؤشر الأولوية من 0 إلى 100، وقرار (Urgent / Schedule / Monitor)، وسلايدر قبل/بعد، والتحميل |
| `pages/2_Damage_Map.py` | صوركم اللي فيها GPS تطلع على خريطة، ومعها قائمة شغل مرتبة بالأولوية وكشف للبلاغات المكررة |
| `pages/3_Model_Results.py` | أرقامكم الحقيقية من التقرير: run 14 والـ baseline وتقسيم الدول |
| `pages/4_Priority_Score.py` | شرح معادلة الأولوية مع سلايدرات للأوزان، واختبار ±20% |
| `pages/5_About.py` | الفريق والبيانات والحدود والخصوصية |
| `priority.py` | معادلتكم من الريبو، منسوخة زي ما هي |
| `utils.py` | الأشياء المشتركة: تحميل النموذج والكشف وGPS وكشف التكرار والتصميم |

> Streamlit يسوي القائمة الجانبية لحاله من ملفات مجلد `pages/`. الرقم اللي في أول اسم الملف يحدد ترتيب الصفحة.

---

## الخطوة 7: أول تعديل لك (عشان تتعلمين)
1. افتحي `.streamlit/config.toml` وغيري `primaryColor` للون ثاني، مثلاً `"#00C2A8"`.
2. احفظي، ورجعي للمتصفح واضغطي **R**. بتشوفين اللون تغير.
3. افتحي `Home.py` وغيري الجملة اللي تحت العنوان، واحفظي. بيطلع لك فوق زر **Rerun**، اضغطيه.

## الخطوة 8: عبي الأرقام الحقيقية
- `Home.py`: دوري على `# TODO` وحطي عدد صور التدريب و mAP وعدد الدول.
- `pages/3_Model_Results.py`: حطي أرقام كل فئة من التقرير بدال الأصفار، واحذفي سطر `st.warning`.

## الخطوة 9: صور الخريطة (أقوى جزء في العرض)
- لازم يكون **الموقع مفعّل في كاميرا الجوال** وقت التصوير.
- لا ترسلين الصور بالواتساب لأنه يمسح الـ GPS. انقليها بـ AirDrop أو كيبل أو Google Drive.
- لما تختبرين صفحة الخريطة، ارفعي 5 إلى 10 صور من شارع واحد.

## الخطوة 10: انشريه أونلاين (اختياري، بس يبهر الحكام)
1. ارفعي المجلد على GitHub. حجم `best.pt` لـ YOLO11s حوالي 22MB وهذا مقبول.
2. ادخلي share.streamlit.io وسجلي دخول بحساب GitHub.
3. اختاري New app، وبعدين المستودع، وحطي `Home.py` كملف رئيسي، واضغطي Deploy.
4. ملف `packages.txt` موجود عشان مكتبة OpenCV تشتغل على السيرفر.

---

## سيناريو العرض قدام الحكام (3 دقائق)
1. **الرئيسية:** المشكلة والفئات الأربع (30 ثانية)
2. **تحليل صورة:** ارفعي صورة فيها حفرة، حركي سلايدر قبل/بعد، وبيّني درجة حالة الطريق والتوصية (60 ثانية)
3. **الخريطة:** ارفعي صور الشارع اللي صورتوه، وخلي الخريطة تتعبى قدامهم، واضغطي على أسوأ نقطة (60 ثانية)
4. **النتائج:** ليش YOLO11 أحسن من ResNet-18 (30 ثانية)

## مشاكل ممكن تواجهك
| المشكلة | الحل |
|---|---|
| `streamlit: command not found` | ما فعّلتي البيئة. ارجعي للخطوة 3 |
| `Model file not found` | تأكدي إن الملف اسمه `best.pt` وإنه داخل `models/` |
| الخريطة تقول No GPS found | الصورة انرسلت بالواتساب أو الموقع كان مقفول في الكاميرا |
| التطبيق بطيء أول مرة | طبيعي، النموذج يتحمّل أول مرة بس وبعدها يصير سريع |
